# Чек-лист скриншотов для отчёта

Этот файл — рабочий помощник для отчёта по лабораторной. Всего нужно **12 снимков**, они пронумерованы в порядке выполнения работы. Снимайте по порядку — тогда ничего не придётся переделывать. README репозитория не содержит заглушек под скриншоты — снимки вставляются в **отдельный отчёт** (документ для преподавателя). Этот файл можно не коммитить в репозиторий — он только для вас.

## Как сделать скриншот

- **Терминал Codespaces** — скриншот окна браузера с видимой командой и её выводом. Горячие клавиши: Windows — `Win+Shift+S`; Linux — `PrtSc` / `Shift+PrtSc`; macOS — `Cmd+Shift+4`.
- **Страницы GitHub** (Actions, Releases) — скриншот окна браузера с нужной вкладкой. Для Actions сначала откройте конкретный прогон, для Releases — конкретный релиз.

## Как вставить скриншоты в отчёт

**Способ 1 — отдельный документ (Word / Google Docs / LibreOffice):**

1. Откройте документ отчёта в нужном разделе.
2. Перетащите PNG в документ или: **Вставка → Рисунок** (Word: Вставка → Рисунки → С устройства; Google Docs: Вставка → Изображение → Загрузить с компьютера).
3. Под снимком добавьте подпись, например: *Рисунок 2 — тесты в Docker, 2 passed*.
4. Ориентир: снимки 1–4, 10, 12 — терминал Codespaces; снимки 5–9, 11 — страницы GitHub (репозиторий, Actions, Releases).

**Способ 2 — если преподаватель просит скриншоты в репозитории:**

1. В Codespaces сохраните снимки в папку `images/` с именами `01-structure.png`, `02-tests-docker.png`, ..., `12-version-020.png`.
2. Вставьте в нужный файл ссылку:

   ```markdown
   ![Структура проекта](images/01-structure.png)
   ```

3. Закоммитьте и запушьте:

   ```shell
   git add images
   git commit -m "docs: add screenshots"
   git push origin main
   ```

## Важные мелочи

- Репозиторий должен быть **публичным** — иначе бейджи CI/Release и страницы Releases будут недоступны преподавателю.
- Скриншоты никак не влияют на пайплайн — их можно снимать до, во время и после релизов; теги и бинарники от этого не меняются.
- На снимках терминала должна быть видна и команда, и её вывод — так преподавателю проще проверить выполнение.
- Перед снятием скриншотов Actions убедитесь, что прогон завершён и горит зелёная галочка.
